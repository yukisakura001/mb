# MatchBox (mb)

## 概要

よく使うコマンドをカテゴリ別に登録し、CLI 上で素早く呼び出してクリップボードにコピーする Rust 製の CLI ツールです。
プログラミング中にメモ帳や別アプリを開かずに、ターミナルだけでコマンドを引き出せます。

## 使用用途

- npm / pip / cargo / docker などのコマンドをカテゴリ別に登録する。
- 登録したコマンドを対話的に選択し、クリップボードにコピーする。

## 導入方法

### 実行ファイルを使用する場合

release からダウンロードしてください。

### Cargo を用いてビルドする場合

```bash
git clone https://github.com/yukisakura001/mb
cd mb
cargo build --release
```

## コマンド一覧

`mb` はどのサブコマンドを実行する場合も、まず `config.json` が存在しなければ自動生成します。

- **mb**

  - 引数なしで実行した場合は何もせず、`引数がありません。` と表示します。

- **mb init**

  - `config.json` を削除して初期状態で作り直します。既存の登録内容はすべて失われます。
  - 初期状態では `npm` カテゴリに `npm run dev` が 1 件登録されています。

- **mb set**

  - コマンドを新規登録します。`カテゴリ名` → `コマンド名` → `コマンド` の順に入力します。
  - カテゴリは事前作成不要で、入力した名前がそのまま使われます（既存カテゴリ名を入力すればそこに追加されます）。

- **mb run [カテゴリ名]**

  - 登録済みコマンドを選択し、その実行文字列をクリップボードにコピーします（コマンド自体の実行はしません）。
  - カテゴリ名を省略した場合は、カテゴリ選択 → コマンド選択の 2 段階で選びます。
  - カテゴリ名を指定した場合は、そのカテゴリのコマンド一覧から直接選択します。

- **mb del [カテゴリ名]**
  - 登録済みコマンドを削除します。選択の流れは `mb run` と同じです。

上記以外の引数を渡した場合は `不明なコマンドです。` と表示されます。

## 使用例

### 初期化

```bash
mb init
# config.jsonを初期化しました。
```

### コマンドの登録

```bash
mb set
# カテゴリ名を入力してください: docker
# コマンド名を入力してください: 全コンテナ表示
# コマンドを入力してください: docker ps -a
# コマンドを登録しました。
```

### コマンドの呼び出し

```bash
mb run
# カテゴリを選択してください → コマンドを選択してください
# コマンドをクリップボードにコピーしました: docker ps -a

mb run docker
# dockerカテゴリのコマンド一覧から直接選択
```

### コマンドの削除

```bash
mb del docker
# コマンドを選択してください
# コマンドを削除しました: 全コンテナ表示: docker ps -a
```

選択画面ではコマンドが `コマンド名: コマンド` の形式で表示されます。

## 設定ファイル

設定はカレントディレクトリの `config.json` に保存されます。
パスは相対パスで扱われるため、**`mb` を実行したディレクトリごとに別の `config.json` が使われます**。

JSON を直接編集することも可能です。カテゴリは各エントリの `category` フィールドで表現されるフラットな配列構造です。

```json
[
  {
    "name": "全コンテナ表示",
    "command": "docker ps -a",
    "category": "docker"
  },
  {
    "name": "イメージビルド",
    "command": "docker build -t myapp .",
    "category": "docker"
  },
  {
    "name": "npm実行",
    "command": "npm run dev",
    "category": "npm"
  }
]
```

`config.json` が見つからない場合や JSON の形式が正しくない場合は、その旨を表示して空のリストとして扱います。
